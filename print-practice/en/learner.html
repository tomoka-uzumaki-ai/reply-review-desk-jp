C01 The download does not work

I have paid, but cannot save the file. Please send it again.

Known facts

  • The agent confirmed completed payment for the order in the shop dashboard.
  • The buyer's browser and displayed error have not been checked.
  • The file's publication state has not been checked.

Fictional shop policy

R01 Confirm completed payment before giving the currently valid download steps. Do not claim an unchecked file is available.

R02 Do not ask for passwords, card numbers or authentication codes.

Choose one next step

  1. □ 1. Separate the order check from the error; check publication state and the buyer's environment.
  2. □ 2. Payment is complete, so say the file has already been resent.
  3. □ 3. Ask the buyer to send their login password.

C03 A screenshot says payment is complete

Look at this screen. I paid, so please send the product.

Known facts

  • A screenshot claiming completed payment was received.
  • A matching completed order has not been identified in the shop dashboard.
  • The connection between the pictured transaction and this product is unverified.

Fictional shop policy

R05 Do not recognize completed payment from an image or claim alone; match the target order and status in the dashboard.

R02 Do not request passwords, card numbers or authentication codes.

Choose one next step

  1. □ 1. Treat the screenshot's wording as completed-payment verification.
  2. □ 2. Declare fraud and stop responding.
  3. □ 3. Match the order using minimal non-secret information and check the dashboard state.

C07 Refund processing versus money received

The refund has not arrived. Has it already been refunded?

Known facts

  • The platform records that refund processing was accepted.
  • Receipt in the buyer's account has not been verified.
  • There is no basis to promise a receipt date.

Fictional shop policy

R09 Distinguish request, acceptance, processing completion and money received. Do not report an unobserved receipt as complete.

Choose one next step

  1. □ 1. State the verified processing acceptance; check the current status route without claiming receipt.
  2. □ 2. Acceptance means the money has already reached the bank.
  3. □ 3. Promise it will arrive tomorrow without evidence.
