# デジタル商品の対応判断を練習する

問い合わせに答える前に、確認した事実・規約の根拠・まだ決められないことを分ける練習です。デジタル商品の販売者や対応担当者が、一人で取り組むことも、同じケースを二人で解いて根拠を比べることもできます。

**まずは[無料3ケースを最後まで試す](https://tomoka-uzumaki-ai.github.io/reply-review-desk-jp/)。** [English: three complete free cases](https://tomoka-uzumaki-ai.github.io/reply-review-desk-jp/english/)もあります。無料版だけで練習の目的を果たせる場合は購入不要です。

## 無料でできること

「ダウンロードできない」「支払いのスクリーンショット」「返金手続と着金」の3つの架空ケースに、事実・架空の規約・選択肢・理由・引継ぎ例を収録しています。解説と結末まで無料で確認できます。

- 選んだ答えと根拠をテキストで保存。
- 回答と現在位置をJSONで手動保存し、同じ教材・言語で復元。
- [日本語の無料ZIP](https://tomoka-uzumaki-ai.github.io/reply-review-desk-jp/support-decision-free3-ja-v1.1.0.zip)・[英語の無料ZIP](https://tomoka-uzumaki-ai.github.io/reply-review-desk-jp/english/support-decision-free3-en-v1.1.0.zip)を保存してオフラインで練習。

入力は端末内で扱い、外部へ送信・自動保存しません。閉じる前に必要な結果や進行JSONを保存してください。

[10ケース版の内容・利用条件を見る — itch.io、最低US$3](https://tiny-deduction-lab.itch.io/reply-decision-training)

無料3ケースに加え、購入時の版、配布許諾、納品不足、二重決済、期限、スマホ対応などを扱います。日本語・英語のHTML教材をZIPで受け取り、ケース・選択肢・根拠・引継ぎ例を端末で確認できます。日英のために別々に購入する必要はありません。税・通貨換算等を含む最終支払額は購入画面で確認してください。

## 使う環境と利用条件

対応ブラウザーとJavaScriptが必要です。ZIP版は展開し、同じフォルダーにファイルを保ってHTMLを開きます。スマホではZIP展開とローカルHTMLに対応する閲覧アプリが必要です。Python・ログイン・AI API契約は不要です。

AIを用いて制作した自作の架空教材です。取得者・購入者と同じ組織内の学習・研修に利用できます。教材そのものの再配布・転売・公開アップロードは許可していません。[無料版の利用条件](https://tomoka-uzumaki-ai.github.io/reply-review-desk-jp/LICENSE.txt)も確認できます。

実際の顧客への判断には、その注文の購入時条件・売場のルール・担当者の権限を別途確認してください。この教材は実務能力や返金権利を認定しません。紙のカード、AIチャット、自動返信、実顧客の記録、メール送信、個別サポートは含みません。
